# ADR-002：单 Agent 有界调查与完整性审计

- 状态：Accepted
- 日期：2026-09-27

## 背景

0.1 的确定性基线每次查询全部数据源，不能根据症状调整顺序或在证据足够时提前停止。项目需要验证 Agent 的动态调查价值，但不应同时引入模型不确定性、多 Agent 并发和生产写操作。

## 决策

0.2 引入一个策略可替换的有界 Agent。默认策略保持确定性，只能产生 `query`、`finish`、`escalate` 三类结构化动作。查询统一经过只读网关，调查受步骤、查询、时间和重复动作预算约束。结论需要至少两个独立来源支持。

所有关键动作追加到 SQLite 审计链。开发模式使用 SHA-256；配置独立密钥后使用 HMAC-SHA256。API 和 CLI 共用同一个 composition root，避免安全策略漂移。

## 后果

优点：动态查询、提前停止、失败降级、幂等复用和审计都能在固定数据上复现；未来模型策略和真实工具可独立替换。代价：SQLite 审计只承诺单进程串行写入，静态 Token 不适合公网，多 Agent 和自动处置继续被排除。
