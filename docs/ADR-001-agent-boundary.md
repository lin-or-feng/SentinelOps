# ADR-001：先建立确定性基线，再引入 Agent

- 状态：Accepted
- 日期：2026-09-27

## 背景

事故诊断最终需要动态调查，但在没有固定数据集、评分指标和工具边界之前直接实现多 Agent，无法判断复杂度是否带来真实收益。

## 决策

0.1 版本只实现确定性诊断基线。所有数据通过只读端口访问，报告必须引用 Evidence ID。Agent、向量库、消息队列和分布式组件暂不进入默认路径。

## 后果

优点：行为可复现、测试简单、可作为后续消融基线。缺点：规则无法处理未知故障或动态决定查询路径。该缺点将在 0.2 的单 Agent 实验中用固定评测集量化，而不是凭感觉判断。
